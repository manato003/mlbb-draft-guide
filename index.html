1今のメタと全体の動き

今のプロメタは フレイヤ・アテラス・ヒララ の3体が軸で、そこにリワークされたマーシャが割り込んでいる。試合は短く、序盤のタートルとタワーを取った側が勝ちやすい。

前提となる状況

  • パッチ：オリジナルサーバーは 2.2.16a（10月14日配信）。アウルス・ヒララ・エウドラ・ラファエルが弱体化、カレアが強化。その前の 2.2.16（9月16日）でマーシャがリワークされた。
  • MPL PH Season 18：Aurora Gaming が決勝で Team Falcons を 4-2 で破り優勝。両チームが M8 世界大会（イスタンブール、2026年12月17日〜2027年1月23日）へ。
  • MPL ID Season 18：プレーオフは11月4〜8日にスラバヤで開催中。

試合展開の特徴

  • ブルーサイドが有利。勝率は ID で 58%、PH で 53%。
  • 最初のバンは、レッド側がフレイヤ（PH 52%）とマーシャ（27%）、ブルー側がファニー（20%）とアテラス（16%）。
  • 11〜17分で決着する試合が多い。最初のタートル（2:00）に3〜4人で行くのが定番。
  • 9月28日からは、試合ごとにマップ効果（回復タートル・ゴールデンタワー・視界のウィスプ・空飛ぶ雲）が1つランダムで付く。
  • ランクとプロは違う。ランク上位はマーシャ・マルセル・アルゴス・ラファエルで、フレイヤはランクでは C ティア。フルパならプロの型をそのまま使える。

PH と ID のメタの違い

軸の4体（フレイヤ・アテラス・ヒララ・パキート）は、PH でも ID でもピックとバンの合計で上位4体に入っている。メタの骨格は同じで、違いは「どれを止めて、どれを通すか」と、軸の周りに置くヒーローに出る。PH はシーズンが終わっていて172試合、ID はプレーオフの途中で、190試合（6 Nov）からさらに増えている。

読み取れること

  • バン：PH はフレイヤに集中し（レッド側の最初のバンの52%）、残りの枠でアテラスやファニーを止める。ID はフレイヤ・アテラスに加えて、マルセル・ファニー・ヒララまでバンが広く散る。
  • ピック：PH はヒララを軸に、バラッツ・ガトートカチャ・ミノタウロスのような前衛を厚くする組み立てが多い。ID はクラウド・アリス・燭心など、PH の上位に無いヒーローも軸の周りで使われる。
  • 勝率の差の読み方：ピックが数十回の勝率は、リーグの間で10ポイントほど差があっても偶然で説明できる範囲にある。差を読むのは、ピック数とバン数の違い（どれを止めるか、どれを通すか）を先にする。

2強い構成の3つの型と理想ピック

用意する型は3つと派生1つ。メインは②アサシンジャングル型で、フレイヤかアテラスの少なくとも一方が空いたら①（もう一方は第3章の代わりの候補で埋める）、相手が回復構成なら③か単独狩りに切り替える。フレイヤとアテラスはほぼ毎試合バンされるので、①をメインにすると型が崩れやすい。

① バースト集団戦型（アテラス＋フレイヤ）

  • 勝ち筋：アテラスが敵をまとめて引き寄せ、フレイヤが10秒間の強化状態で飛び込む。範囲魔法のミッドが追撃して、集団戦を一瞬で終わらせる。
  • 実例：ONIC PH が フレイヤ / ノーラン / リリア / クラウド / アテラス で、14分で TNC に勝利（左から EXP / ジャングル / ミッド / ゴールド / ローム）。
  • 弱点：洗礼、ディガーのウルト、散開した陣形、フォビウス・マイシータール。

② アサシンジャングル型（メイン）

  • 勝ち筋：ヒララやファニーで序盤の小競り合いとタートルを取る。硬い前衛2枚が集団戦の入口を作り、15分前後で終わらせる。
  • 実例：Aurora が バラッツ / ヒララ / 燭心 / フレイヤ / ガトートカチャ でプレーオフ初戦を勝利。ONIC も カーディアン / ヒララ / リリア / シーシー / マーシャ で勝利。
  • 弱点：セイバー・クッフラー・マイシータールのような確実に止めるスキル、試合を長引かせること。

③ 回復持久型（マルセル・ラファエル ＋ マークスマン）

  • 勝ち筋：粘り強い前衛と回復で集団戦を長引かせ、その間にマークスマンが安全に火力を出し続ける。
  • 実例：ONIC が アリス / アウルス / 燭心 / クラウド / マルセル、Team Liquid PH が ルビー / パキート / エウドラ / クリント / マルセル で勝利。
  • 弱点：アンチヒール装備、一瞬で倒しきるバースト、ヒーラーを先に狙われること。ラファエルとアウルスは 2.2.16a で少し弱体化済み。
  • ソロランクではこの型が一番安定する。

派生：ゴールドにファイターを置く

マークスマンの層が薄いので、ゴールドにフレイヤ・パキート・シーシーを置いて前衛寄りに組む。②と組み合わせることが多い。ロームが早めにゴールドを離れられるので、序盤から試合を動かしやすい。

実例の出典：MLBBDex MPL PH S18

3型ごとの枠の役割と代わりのヒーロー

第2章の理想の5体を基準に、各ヒーローがその構成で果たしている役割を言葉にした。理想のヒーローが取れなかったら、同じ枠の「代わりの候補」から、役割を果たせるヒーローを選ぶ。候補は役割に近い順に並べ、理由はヒーロー別の強み・弱みから取った。「この枠をこのヒーローにしたら、別の枠はこれ」という組み合わせの指定はせず、5つの役割が埋まっているかで判断する。

① バースト集団戦型（フレイヤ / ノーラン / リリア / クラウド / アテラス）

枠 理想 役割 代わりの候補
ローム アテラス 集団に CC をかけながら仕掛ける。この型の起点 範囲 CC で一気に仕掛けられるロームなら代わりになる。カレア、カチャ（ウルトで範囲の敵を全員引き寄せる）、クッフラー（集団に飛び込んで CC をかける）、ガトートカチャ（突進と CC で前に出る。可能性のある候補）、カーミラ（範囲の拘束。続けられなくはない）。ミノタウロスは敵を引っ張ってこられないので向かない
EXP フレイヤ アテラスのウルトに合わせて一番の火力を出し、CC で追撃する。単体の DPS も高く、ウルトの飛び込み中は CC を受けない 集団戦に強い EXP のファイターなら、フレイヤより一段落ちるが型は成り立つ。ラインロック、ゾン。バラッツは前衛で単体 CC のため役割が違う
ミッド リリア 序盤から、2人の仕掛けに合わせて奥の敵までダメージを届け、追撃もする 燭心（集団戦から逃げる敵をウルトの瞬間移動で追い、CC で戦場に戻す）、オーロラ、カグラ（範囲バーストと機動力。序盤に詰められると弱い）
ゴールド クラウド ミッドに近い立ち位置。後半になるほど集団戦のダメージを上乗せする アイーダ（複数の敵を貫く攻撃）、ハナビ（敵が固まる集団戦に強い）、マイヤ
ジャングル ノーラン 味方が削った敵を機動力で追ってキルを回収する。全体にダメージも足す パキート（張り付いて殴り合う）、ファニー（機動力と高いバースト。操作が難しい）
  • フレイヤかアテラスのどちらかが消えても、上の代わりの候補で①を続けられる。どちらの代わりも、理想のヒーローよりは一段落ちる。
  • 相手にディガー・フォビウス・マイシータールが見えたら危険（アテラスのウルトとフレイヤの飛び込みが止められる）。
  • アテラスは4レベル（ウルト）を最優先する。ノーランは序盤はファームで4レベルに乗せ、集団戦ではフレイヤと一緒に飛び込んで残った敵を仕留める。

② アサシンジャングル型（バラッツ / ヒララ / 燭心 / アイーダ / カーミラ）（メイン）

枠 理想 役割 代わりの候補
ジャングル ヒララ 主役。序盤の小競り合いとタートルで主導権を取り、後衛を狩る パキート（序盤の殴り合いと張り付き）、ファニー（機動力とバースト）、ノーラン（入って抜けるバースト）
ローム カーミラ CC で集団戦の入口を作る。ジャングラーと一緒に動いて視界を取る ガトートカチャ（突進と CC で味方の前に出る）、マーシャ、カレア
EXP バラッツ 硬い前衛。序盤はレーンを守り、タートルと集団戦で入口を作る ウラノス（持久戦と前線の維持）、カーディアン（範囲のタンク。ONIC がこの型の EXP で使用）、マーシャ（3本の HP と吸血で粘る）
ミッド 燭心 捕まえる側。倒しきるのではなく、CC で敵を捕まえて味方にキルを取らせる。逃げる敵はウルトの瞬間移動で追う。ウルトのシールドで1人でも耐えられる エウドラ（倒しきる、または味方が回収できるまで削る）、セリナ（スキル2のスタンや視界取りで支える面もあるが、ミッドで取るなら求められるのはダメージ）。どちらも燭心とは違い、ダメージを出す側
ゴールド アイーダ マークスマンなら序盤は無理せずファームし、集団戦で火力を出す クラウド、クリント。マークスマンが取れなければファイター（フレイヤ・パキート・シーシー）を置き、前に出て前衛を厚くする（第2章の派生）
  • 相手にセイバー・クッフラー・マイシータールが見えたら、アサシンが捕まらないよう EXP とロームを硬いヒーローにする。
  • 長引くと不利なので、ロームとミッドは序盤から動けるヒーローを選ぶ。

③ 回復持久型（アリス / アウルス / 燭心 / クラウド / マルセル）

枠 理想 役割 代わりの候補
ゴールド クラウド 勝ち筋。回復と前衛に守られながら火力を出し続ける。序盤はロームが長めに守る クリント（ミニオン越しにポークできる。10〜16分がピーク）、アイーダ
ローム マルセル 拘束か回復でマークスマンを守り、集団戦を長引かせる ラファエル（回復と移動速度、視界）、エスタス（回復と周囲のスロー）、ミノタウロス（範囲 CC と回復。飛び込んでくる相手を止める）
EXP アリス 粘る前衛。後衛を守りながら長く戦う ルビー（引き寄せて回復しながら1人を捕まえる）、ウラノス（戦闘が続くほど回復する）
ミッド 燭心 入ってくる敵を CC で止めて接近を拒否し、相手の集団戦をディスエンゲージする。あわせて範囲ダメージで長期戦を支える。キルを取らせるより守る方に CC を使う リリア（遠距離からの範囲ダメージ）、ベルス（炎上の3スタックでスタン）
ジャングル アウルス ファーム優先。タートル・ロードなど目的物の確保を担う パキート（Team Liquid PH がこの型で使用）
  • 相手にバーストアサシンが多いときは、アンチヒール装備を積まれる前提で構える。ラファエルとアウルスは 2.2.16a で少し弱体化済み。
  • ミノタウロスはプロでは登場率41%・勝率44%と勝ち切れていないが、ランクは S。

複数レーンで使えるヒーロー（先に取って配置を隠せる）

  • パキート：EXP・ジャングル・ゴールド
  • フレイヤ：EXP・ゴールド
  • マーシャ：EXP・ローム
  • アウルス：ジャングル主体、EXP・ゴールドも可
  • エスメラルダ・シーシー：EXP・ゴールド

ミッドのヒーロープール（このチーム用）

  • メイン：リリア、燭心。①と③の型を両方カバーできる。燭心はランクでは B ティアだが、MPL PH では44ピック・勝率57%。連携前提のヒーローなのでフルパ向き。
  • バースト枠：エウドラかカグラ。回復構成や②の型で使う。
  • 余裕があれば：オーロラ（①の型専用）、バレンティナ（敵のウルトをコピーできる。相手にアテラスがいればこちらもアテラスのウルトを撃てる）。
  • 優先度が低い：ノヴァリア。スキルが当たらなかったときの保証が薄く、短い試合に合わせにくい。

4バンピック（先行・後攻別）

ブルー（先行）は強いヒーローを先に確保し、レッド（後攻）は最後のピックでカウンターを出す。以下は MPL 方式のドラフトが前提。ランクで形式が違う場合も考え方はそのまま使える。

ドラフトの順番

  1. バン（1回目）：両チーム3つずつ（ブルーとレッドが交互）
  2. ピック：ブルー1 → レッド1・2 → ブルー2・3 → レッド3
  3. バン（2回目）：両チーム2つずつ（レッドから）
  4. ピック：レッド4 → ブルー4・5 → レッド5（最後のピックはレッド）

ブルーサイド（先行）

  • バン1回目：ファニーとマーシャを優先。残り1つは自分たちの型を壊すヒーロー（①ならディガー、②ならセイバーやクッフラー）。フレイヤとアテラスはあえて残し、相手のバンを使わせるのも手。
  • ピック1：最強か、複数レーンで使えるヒーロー。優先順は フレイヤ → アテラス → パキート → ヒララ。フレイヤが残っていたら即確保。
  • ピック2・3：型の軸を完成させる。アテラスを取れたら範囲ダメージのミッドとフレイヤ（なければ硬い EXP）。パキートを取れたらヒララかノーランと、カーミラかガトートカチャ。
  • バン2回目：相手が見せた3体から、まだいない役割の候補を潰す（例：ゴールドがいなければクラウドかアイーダ）。
  • ピック4・5：最後はレッドにカウンターされるので、崩れにくい安定したヒーローで締める（ゴールドならクラウド、ミッドなら燭心）。

レッドサイド（後攻）

  • バン1回目：定番はフレイヤ・マーシャ、そしてアテラスかヒララ。相手の得意ヒーローが分かればそれを優先。
  • ピック1・2：2体続けて取れるのが強み。相手の最初がアテラスならパキート＋ヒララ。相手の最初がパキートならアテラス＋マルセル、フレイヤが残っていればアテラス＋フレイヤ。
  • ピック3：複数レーンで使えるヒーローで役割を隠す。
  • バン2回目（レッドから先）：相手の型に必要な残りのパーツを潰す（例：相手にロームがいなければカーミラとマルセル）。
  • ピック4：型を完成させるヒーロー。
  • ピック5（最後）：ミッドが取るのが理想。相手が回復構成ならエウドラかカグラ、密集する構成ならオーロラかリリア、突撃してくる構成ならベルスか燭心。

バン1回目が終わった時点での型の決め方

  1. フレイヤかアテラスの少なくとも一方が残っている → ①（もう一方は第3章の代わりの候補で埋める）
  2. ヒララかパキートと、硬い前衛が取れる → ②
  3. どちらも取れず、マルセルかラファエルが空いている → ③
  4. 相手がエスタスやラファエルを取った → ミッドをバーストに切り替え、単独狩りの方針に寄せる（第5章参照）

データ出典：MLBBHub ID drafts、MLBBHub PH drafts

5カウンターと回復構成への対策

カウンターピックは「相手の勝ち筋を1つ特定して潰す」こと。統計上の相性差は勝率で+2〜5ポイント程度なので、カウンターだけ取って構成が弱くならないようにする。

メタ上位への対策

相手 効くヒーロー 装備・立ち回り
フレイヤ フォビウス（+4.9）、マイシータール（+4.7）、エスメラルダ、フランコ ドミナント か トライデント、ブレードアーマー。飛び込み中は CC 無効なので、着地してから CC を当てる。10秒の強化状態は逃げて時間を稼ぐ
アテラス マルセル（+5.9）、琥珀（+3.8）、アリス（+3.1）、ディガー、ベルス 洗礼。散開して戦い、目的物の前で固まらない
ヒララ セイバー（+2.7）、フォビウス（+2.3）、ブルーノ（+2.1）、クッフラー、マイシータール 序盤の小競り合いを避けて試合を長引かせる。捕まえればすぐ落ちる
マーシャ 悟空、アルゴス、エスタス、アウルス、ウラノス アンチヒール装備と、長期戦で殴り勝てるファイター

（カッコ内はランクでの相性差。勝率のポイント）注意：マーシャ・マチルダ・ロインはフレイヤに不利なので、フレイヤ対策には出さない。

回復構成（エスタス・ラファエル など）への対策

共通の結論は、長く続く互角の5対5をしないこと。そのうえで構成とタイミングで使い分ける。

  • 単独の敵を拾う：先に1人落として5対4にすれば、回復量の差は関係なくなる。条件を選ばない一番安全な勝ち方。
  • 仕掛けてヒーラーに集中：仕掛けが敵の後衛まで届くときだけ成立（アテラス・カチャの引き寄せ、フランコのフック、裏に回るアサシン）。2〜3秒で落としきる。前衛にしか当たらないと削り負ける。
  • ウルトを使わせてから戦う：エスタスのウルトはクールダウンが長い。使った直後が全員で仕掛けるチャンス。
  • 正面の5対5を避ける：サイドのタワーや、相手がいない間のタートル・ロードを取る。
  • アンチヒール装備を役割ごとに分担：トライデント（物理）、ヒートロッド（魔法）、ドミナント（タンク。攻撃を受けたときだけ、1秒しか効果がない）。同じ効果を重ねても強くならないので、複数の敵に当て続けられるよう分担する。回復の強い敵が2体以上なら全員が1つずつ。
  • ミッドの選び方：単独狩りならエウドラやセリナ。仕掛けて集中するならカグラやオーロラ。燭心は回復役が1枚なら「捕まえて投げる役」で使えるが、回復が2枚ならバースト系に切り替える。
  • 自分たちに上の手段がなければ、エスタスは素直にバンする。
